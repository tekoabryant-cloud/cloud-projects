# AWS S3 Backup Manager

## Overview

AWS S3 Backup Manager is a Python automation project that uses the AWS SDK for Python (Boto3) to manage files stored in an Amazon S3 bucket.

The program allows users to upload, list, download, and delete files using Python and AWS cloud storage.

## Features

- Upload files to an Amazon S3 bucket
- List files stored in an S3 bucket
- Download files from an S3 bucket
- Delete files from an S3 bucket
- Error handling using try/except

## Technologies Used

- Python
- AWS S3
- Boto3
- Git
- GitHub
- Visual Studio Code
